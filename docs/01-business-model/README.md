2. БИЗНЕС-КОНТЕКСТ
 Проблема: В мобильной игре Last Day On Earth: Survival опущена значительная часть информации, которая может быть полезна игроку. Узнать её можно только проверив на деле. Также игровая система уведомлений слишком общая и нет возможности отслеживать мелкие внутриигровые события. 
 Решение: Моё приложение выступит решением в плане информационной базы игры с дополнительными функциями. Также будет реализован удобный интерфейс для создания уведомлений на внутриигровые события.
