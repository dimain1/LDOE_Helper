# Глоссарий


|Термин| Определение| Связи/Комментарии|
|---|---|---|
|База игрока|Локация, где игрок может расположить станции крафта и хранилища|Состоит из множества построек, может подвергаться нашествию зомби, и нападению рейдеров|
|База для рейда|Локация другого выжившего,на которую можно совершить рейд|Локация, появяющаяся после выполнения некоторых условий, содержит много лута|
|Безопасная локация|Локация, на которой нет зомби|Таких локаций не много, поселение является одной из них|
|Время отката|Время, когда локация будет обновлена|Внутриигровой таймер по после которго следует обновление локации|
|Домашняя локация|Локация, где распроложена база игрока|Содержит базу игрока, Относительно безопасная|
|Зачистка локации|Процесс в результате которого игрок избавляется от зомби и собирает лут|Зачистка локации может быть как полной, так и частичной. Локации которые не сразу обновляются могут быть зачищены в несколько подходов|
|Зомби|Основные враги игрока, населяющие все не безопасные локации|После убийства оставляют лут|
|Игрок|Потенциальный пользователь системы, который играет в игру LDOE|Вышивший, который обустраивает свою базу, Зачишает локации|
|Крафт|Игровой механизм получения ресурса из других |Основная механика получения большинства продвинутных ресурсов|
|Локация|Место, где игрок может проявить активность|Может содержать зомби, лут. Может мгновенно обновлятся, а может иметь время отката|
|Лут|Ресурсы полученные в результате деятельности игрока|Основную часть лута игрок получает в процессе зачистки локации с зомби и хранилищ с лутом|
|Материал|Ресурс используемый в крафте, либо обрабатываемый в станции|Большая часть лута выступает в роли материалов|
|Обновление локации|Состояние локации, когда она возвращается к исходному варианту|Событие, в результате которого игрок может потерять часть лута либо получит возможность получить его ещё раз|
|Опасная локация|Локация, на которой есть зомби или другие существа способные навредить игроку|Подавляющее большинство локаций в игре|
|Постройка|Часть базы игрока|Могут быть разрущены в результате нападения зомби|
|Поселение|Дополнительная домашняя локация|Вторая база игрока, но уже состоящая из другого типа построек, так же в отличии от основной локации является полностью безопасной|
|Продвинутые ресурсы|Ресуры получаемые в результате крафта или зачистки определённых локаций|Редкие ресурсы, либо ресурсы на создание которых уходит много времени|
|Рейд|Нападение на базу для рейда с целью получения лута|Одна из самых прибыльных по луту активностей игрока, но требует специальные ресурсы|
|Ресурс|Игровая единица||
|Станция крафта|Постройка, которая преобразует один вид ресурса в другой спустя время|Имеет множество вариаций, может требоваться топливо, время обработки разниться от нескольких минут до нескольких часов|
|Топливо для станции|Ресурсы, которые поддерживают возможность работы станций крафта|Небольшая категория ресурсов, отличающиеся для разных станций|
|Хранилище|Постройка, которая используется для хранения ресурсов игрока|Имеет ограниченную вместимость|
|Хранилище с лутом|Часть опасной локации, содержит в себе лут|Имеет большой разброс по содержимому. В редких случаях содержит продвинутые ресурсы|
|Энергия|Числовой показатель расходуемый во время перемещения между локациями |Востанавливается с течением времени|
