# Глоссарий


|Термин| Определение| Связи/Комментарии|
|---|---|---|
|База игрока|Относительно безопасная локация, где игрок может расположить станции крафта и хранилища||
|База для рейда|Локация другого выжившего,на которую можно совершить рейд||
|Время отката|Время, когда локация будет обновлена||
|Домашняя локация|Место, где распроложена база игрока||
|Игрок|Потенциальный пользователь системы, который играет в игру LDOE||
|Крафт|Игровой механизм получения ресурса из других ||
|Локация|Место, где игрок может перемещаться, собирать ресурсы и сражаться с зомби||
|Лут|Ресурсы полученные в результате деятельности игрока||
|Материал|Ресурс используемый в крафте, либо обрабатываемый в станции||
|Обновление локации|Состояние локации, когда она возвращается к исходному варианту||
|Постройка|Часть базы игрока||
|Рейд|Нападение на базу для рейда с целью получения лута||
|Ресурс|Игровая единица||
|Станция крафта|Постройка, которая преобразует один вид ресурса в другой спустя время||
|Топливо для станции|Ресурсы, которые поддерживают возможность работы станций крафта||
|Хранилище|Постройка, которая используется для хранения ресурсов игрока||
|Энергия|Числовой показатель расходуемый во время перемещения между локациями ||
