# BUC - диаграмма

Назначение - показать, какие бизнес-действия система должна поддерживать.


## Ключевые элементы:

- Бизнес-акторы: Пользователь, Администратор
- Бизнес-преценденты:
    - Получение информации об игре
    - Управление своими игровыми событиями
    - Создание напоминания о событии
    - получение уведомление о событии
    - Обновление данных игры
    - Модерирование контента игры
