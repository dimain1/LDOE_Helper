# Руководство пользователя — LDOE-Helper

## О приложении

LDOE-Helper — мобильное Android-приложение для игроков в Last Day on Earth. Позволяет отслеживать игровые события с таймерами, хранить шаблоны повторяющихся действий и быстро обращаться к базе знаний прямо во время игры через наложенный виджет (overlay).

---

## Требования

- Устройство: Android
- Интернет-соединение: требуется для синхронизации (приложение работает офлайн с локальным кэшем)
- Разрешение «Поверх других приложений»: требуется для overlay-виджета

---

## 1. Регистрация и вход

### 1.1 Регистрация

При первом запуске приложения необходимо создать аккаунт.

1. Перейдите на вкладку **Настройки** (иконка в нижней панели навигации)
2. Нажмите кнопку **«Зарегистрироваться»**
3. В открывшемся окне заполните поля:
   - **Логин** — уникальное имя пользователя
   - **Email** — адрес электронной почты
   - **Пароль** — не менее 8 символов
4. Нажмите **«Зарегистрироваться»**

После успешной регистрации вы автоматически войдёте в аккаунт.

> **Примечание:** первый зарегистрированный пользователь в системе получает роль **Администратора**. Все последующие пользователи получают роль **Пользователь**.

### 1.2 Вход в аккаунт

Если у вас уже есть аккаунт:

1. Перейдите на вкладку **Настройки**
2. Нажмите кнопку **«Войти»**
3. Введите логин и пароль
4. Нажмите **«Войти»**

### 1.3 Выход из аккаунта

1. Перейдите на вкладку **Настройки**
2. В разделе **«Аккаунт»** нажмите **«Выйти из аккаунта»**

## 2. Главный экран

Главный экран — отправная точка приложения. Он содержит:

- **Игровой оверлей** — кнопка запуска/остановки плавающего виджета
- **Быстрый доступ** — четыре кнопки перехода к основным разделам (Настройки, Шаблоны, Мои события, База данных)
- **Предстоящие события** — список активных событий с таймерами обратного отсчёта
- **Закреплённые** — список элементов базы знаний, закреплённых для быстрого доступа


![Главный экран](../08-ui/mobile/home.png)

### Взаимодействие с элементами

| Действие | Результат |
|---------|----------|
| Нажать на событие в списке | Открыть детали события |
| Нажать на иконку корзины рядом с событием | Удалить событие |
| Нажать на иконку булавки рядом с контентом | Открепить элемент |

---

## 3. Управление событиями

### 3.1 Просмотр событий

Перейдите на вкладку **События** (иконка колокольчика). Отображается список всех ваших событий с таймером обратного отсчёта до времени начала и окончания.


![Экран событий](../08-ui/mobile/events.png)

### 3.2 Создание события

1. На экране **События** нажмите кнопку **«+»** (создать)
2. Заполните форму:
   - **Название** — обязательное поле (максимум 100 символов)
   - **Описание** — необязательное поле
   - **Дата и время начала** — нажмите на поле для открытия выбора даты и времени
   - **Дата и время окончания** — задаётся вручную или автоматически при выборе шаблона
   - **Шаблон** — необязательное поле; при выборе шаблона имя и время окончания заполняются автоматически
3. Нажмите **«Сохранить»**

![Создание события](../08-ui/mobile/modal-event-create.png)

### 3.3 Просмотр деталей события

Нажмите на любое событие в списке — откроется модальное окно с подробной информацией: название, описание, изображение шаблона, дата начала и окончания.

![Просмотр события](../08-ui/mobile/modal-event-view.png)

### 3.4 Редактирование события

1. Нажмите на событие для просмотра деталей
2. Нажмите кнопку **«Редактировать»**
3. Измените нужные поля
4. Нажмите **«Сохранить»**

### 3.5 Удаление события

Нажмите иконку корзины рядом с событием в списке. Удаление необратимо.

## 4. Шаблоны событий

Шаблон — заготовка для повторяющихся событий. Содержит название и длительность. При создании события по шаблону время окончания рассчитывается автоматически.

### 4.1 Просмотр шаблонов

Перейдите на вкладку **Шаблоны**.


![Экран шаблонов](../08-ui/mobile/templates.png)

### 4.2 Создание шаблона

1. На экране **Шаблоны** нажмите кнопку **«+»**
2. Заполните форму:
   - **Название** — обязательное поле
   - **Описание** — необязательное
   - **Длительность** — время в минутах; на его основе рассчитывается время окончания события
   - **Изображение** — необязательное; выбирается из галереи (максимум 5 МБ)
3. Нажмите **«Создать»**


![Создание шаблона](../08-ui/mobile/modal-template-create.png)

### 4.3 Редактирование и удаление шаблона

Нажмите на шаблон для просмотра деталей, затем выберите **«Редактировать»** или **«Удалить»**.

---

## 5. База знаний

База знаний содержит игровой контент: предметы, персонажей, рецепты и другие объекты, добавленные администратором.

### 5.1 Просмотр контента

Перейдите на вкладку **База данных**. Контент отображается в виде списка и может быть отфильтрован по категориям (типам).

![База знаний](../08-ui/mobile/info.png)

### 5.2 Просмотр деталей объекта

Нажмите на любой элемент — откроется карточка с изображением, описанием и атрибутами объекта.

![Просмотр контента](../08-ui/mobile/modal-content-view.png)

### 5.3 Закрепление элемента

Нажмите на иконку булавки рядом с элементом, чтобы закрепить его. Закреплённые элементы отображаются на **Главном экране** в разделе «Закреплённые» для быстрого доступа.

Для откреплени — нажмите иконку ещё раз.

---

## 6. Overlay-виджет

Overlay — плавающий виджет, который отображается поверх других приложений, в том числе поверх самой игры.

### 6.1 Запуск overlay

1. На **Главном экране** нажмите кнопку **«Запустить оверлей»**
2. Если разрешение «Поверх других приложений» не выдано — система откроет настройки для его предоставления
3. После предоставления разрешения нажмите кнопку ещё раз

![Overlay меню](../08-ui/mobile/overlay-menu.png)

### 6.2 Функции overlay

Через плавающий виджет доступны:

| Функция | Описание |
|---------|---------|
| Просмотр событий | Список текущих событий с таймерами — без выхода из игры |
| Создание события | Быстрое создание нового события |
| Свернуть виджет | Виджет сворачивается в иконку |

![Overlay события](../08-ui/mobile/overlay-events.png)

### 6.3 Остановка overlay

На **Главном экране** нажмите кнопку **«Закрыть оверлей»**.

## 7. Настройки приложения

Перейдите на вкладку **Настройки** для управления аккаунтом и параметрами.

![Настройки — профиль](../08-ui/mobile/settings_profile.png)

### Раздел «Аккаунт»

| Пункт | Действие |
|-------|---------|
| Редактировать профиль | Изменить логин или email |
| Выйти из аккаунта | Завершить сессию |

### Раздел «Параметры»

| Пункт | Действие |
|-------|---------|
| Уведомления | Включить/выключить push-уведомления о событиях |
| Звуковые эффекты | Включить/выключить звук |
| Тёмная тема | Переключить тему оформления |

### 7.1 Редактирование профиля

1. Нажмите **«Редактировать профиль»**
2. Измените логин и/или email
3. Нажмите **«Сохранить»**

---

## 8. Офлайн-режим

Приложение работает без интернета. Данные хранятся локально в базе Room. При восстановлении соединения изменения автоматически синхронизируются с сервером в фоновом режиме.

| Состояние | Доступные функции |
|-----------|-----------------|
| Онлайн | Все функции, данные синхронизируются |
| Офлайн | Просмотр и создание событий/шаблонов; изменения будут синхронизированы позже |
