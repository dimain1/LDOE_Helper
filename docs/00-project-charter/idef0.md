# IDEF0 — Функциональная модель системы

## Назначение

IDEF0 — методология функционального моделирования (FIPS 183). Описывает систему как набор функций, связанных потоками данных. Каждая функция имеет четыре типа связей:

| Тип | Обозначение | Описание |
|-----|------------|---------|
| **Input** | Вход (левая сторона) | Данные или объекты, потребляемые функцией |
| **Output** | Выход (правая сторона) | Результат выполнения функции |
| **Control** | Управление (верхняя сторона) | Условия и правила, регулирующие функцию |
| **Mechanism** | Механизм (нижняя сторона) | Ресурсы, выполняющие функцию |

---

## Диаграмма A-0 — Контекстный уровень

Показывает систему как **единый функциональный блок** в бизнес-окружении.

### Основная функция

**A0: «Обеспечить информационную поддержку игрового процесса»**

| Элемент | Содержание |
|---------|-----------|
| **Входы** | Данные игры (контент, механики, локации); Действия пользователя (запросы, настройки, создание событий) |
| **Выходы** | Информация об игре (структурированная, отфильтрованная); Уведомления о событиях |
| **Управление** | Внутриигровая логика (правила механик LDOE); Настройки уведомлений пользователя |
| **Механизмы** | Мобильное приложение (Android); Пользователь; Сервер (Spring Boot + PostgreSQL) |

## Диаграмма A0 — Декомпозиция первого уровня

Контекстный блок A0 раскладывается на четыре подфункции для получения детального представления о работе системы.

| Функция | ID | Входы | Выходы | Управление | Механизм |
|---------|----|----|-------|-----------|---------|
| **Ввод данных** | A1 | Данные игры | Игровые объекты в БД | Требования к данным | Администратор, Бэкенд |
| **Управление информацией** | A2 | Запросы пользователя; Игровые объекты из БД | Отфильтрованная информация | Права доступа | Мобильное приложение, Сервер |
| **Обработка событий** | A3 | Параметры события от пользователя | Активные таймеры | Настройки уведомлений | Мобильное приложение, WorkManager |
| **Уведомление пользователя** | A4 | Активные таймеры | Уведомления о событиях | Системные разрешения Android | NotificationManager, Overlay-сервис |

![IDEF0 A0 — Декомпозиция](./images/IDEF0-A0.png)

## Выводы

Диаграмма A-0 фиксирует границы системы и её место в бизнес-среде. Декомпозиция A0 показывает, что система состоит из двух независимых цепочек:

- **Информационная**: Ввод данных → Управление информацией → Пользователь
- **Событийная**: Обработка событий → Уведомление → Пользователь
