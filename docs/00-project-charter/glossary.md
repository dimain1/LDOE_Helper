# Глоссарий

## Описание

Глоссарий фиксирует единое понимание терминов, используемых в проекте. Включает термины двух категорий: **предметная область** (игровые понятия LDOE) и **система** (технические термины приложения LDOE-Helper). Является обязательным справочным документом для всех участников проекта.

---

## Предметная область — игровые термины LDOE

| Термин | Определение | Связи / Комментарии |
|--------|------------|---------------------|
| База игрока | Локация, где игрок располагает станции крафта и хранилища | Может подвергаться нашествию зомби и нападению рейдеров |
| База для рейда | Локация другого выжившего, на которую можно совершить рейд | Появляется при выполнении определённых условий; содержит ценный лут |
| Безопасная локация | Локация, на которой отсутствуют враждебные существа | Поселение и домашняя локация являются примерами |
| Время отката | Промежуток времени до обновления локации | Внутриигровой таймер, по истечении которого локация возвращается к исходному состоянию |
| Домашняя локация | Локация, где расположена база игрока | Содержит базу игрока; относительно безопасна |
| Зачистка локации | Процесс, в результате которого игрок уничтожает зомби и собирает лут | Может быть полной или частичной; локации с откатом можно зачищать в несколько подходов |
| Зомби | Основные враги игрока, населяющие опасные локации | После уничтожения оставляют лут |
| Игрок | Пользователь, играющий в LDOE и использующий LDOE-Helper | Выживший, обустраивающий базу и зачищающий локации |
| Крафт | Игровой механизм получения одного ресурса из других | Основной способ получения продвинутых ресурсов |
| Локация | Место, где игрок может проявить активность | Может содержать зомби, лут; может обновляться мгновенно или иметь время отката |
| Лут | Ресурсы, полученные в результате игровой деятельности | Основная часть добывается при зачистке локаций и хранилищ |
| Материал | Ресурс, используемый в крафте или обрабатываемый на станции | Большая часть лута выступает в роли материала |
| Обновление локации | Возврат локации к исходному состоянию | Событие, после которого игрок может повторно добыть ресурсы |
| Опасная локация | Локация с враждебными существами | Подавляющее большинство локаций в игре |
| Постройка | Составная часть базы игрока | Может быть разрушена в результате нападения |
| Поселение | Дополнительная домашняя локация | Вторая база игрока; полностью безопасна в отличие от основной |
| Продвинутые ресурсы | Ресурсы, получаемые крафтом или зачисткой редких локаций | Редкие ресурсы; их производство требует значительного времени |
| Рейд | Нападение на базу другого игрока с целью получения лута | Одна из наиболее прибыльных активностей; требует специальные расходуемые ресурсы |
| Ресурс | Базовая игровая единица — предмет в инвентаре | Используется для крафта, построек, рейдов |
| Станция крафта | Постройка, преобразующая один вид ресурса в другой за определённое время | Имеет множество вариаций; время обработки варьируется от минут до часов |
| Топливо для станции | Ресурсы, поддерживающие работу станций крафта | Отличаются для разных типов станций |
| Хранилище | Постройка для хранения ресурсов игрока | Имеет ограниченную вместимость |
| Хранилище с лутом | Объект в составе опасной локации, содержащий ресурсы | Содержимое варьируется; в редких случаях — продвинутые ресурсы |
| Энергия | Числовой показатель, расходуемый при перемещении между локациями | Восстанавливается с течением реального времени |

## Термины системы — LDOE-Helper

| Термин | Определение | Связи / Комментарии |
|--------|------------|---------------------|
| GameEvent | Пользовательское игровое событие с таймером | Создаётся пользователем; привязывается к игровому объекту или задаётся вручную |
| GameInfo | Запись в информационной базе приложения | Описывает игровой объект: локацию, ресурс, механику или рецепт крафта |
| Notification | Push-уведомление, генерируемое при срабатывании таймера события | Доставляется системой Android даже когда приложение свёрнуто |
| Overlay-виджет | Плавающий элемент интерфейса, отображаемый поверх других приложений | Позволяет видеть активные события во время игры; требует разрешения `SYSTEM_ALERT_WINDOW` |
| Офлайн-режим | Режим работы приложения без подключения к серверу | Данные берутся из локального Room-кэша; синхронизация при восстановлении сети |
| Room-кэш | Локальная база данных на устройстве пользователя (Android Room) | Обеспечивает офлайн-доступ к игровому контенту и хранение событий |
| JWT | JSON Web Token — механизм аутентификации и авторизации | Access-токен (короткоживущий) + Refresh-токен (долгоживущий) |
| REST API | HTTP-интерфейс бэкенда для взаимодействия мобильного приложения с сервером | Реализован на Spring Boot; документирован через Swagger/OpenAPI |
| WorkManager | Компонент Android Jetpack для выполнения фоновых задач | Используется для планирования срабатывания таймеров событий |
| Синхронизация | Процесс обновления Room-кэша актуальными данными с сервера | Выполняется при наличии интернет-соединения; разрешает конфликты по временной метке |
