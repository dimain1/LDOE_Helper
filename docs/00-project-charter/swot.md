# SWOT-анализ

## Назначение

SWOT-анализ оценивает **внутренние** и **внешние** факторы, влияющие на успех проекта. Результат — основа для выработки стратегии, опирающейся на сильные стороны и нейтрализующей угрозы.

---

## Матрица SWOT

|  | **Возможности (O)** | **Угрозы (T)** |
|--|---------------------|----------------|
| **Сильные стороны (S)** | **SO — Стратегия развития:** использовать силу для реализации возможностей | **ST — Стратегия защиты:** использовать силу для нейтрализации угроз |
| **Слабые стороны (W)** | **WO — Стратегия улучшения:** устранять слабости за счёт возможностей | **WT — Стратегия минимизации:** сократить уязвимости и уклониться от угроз |

---

## Сильные стороны (S) — внутренние преимущества

| # | Фактор | Обоснование |
|---|--------|-------------|
| S1 | Отсутствие прямых конкурентов | Специализированных помощников для LDOE на русскоязычном рынке нет |
| S2 | Многолетний опыт игры в LDOE | Глубокое понимание предметной области и потребностей целевой аудитории |
| S3 | Современный технологический стек | Kotlin + Jetpack Compose + Spring Boot — актуальные поддерживаемые технологии |
| S4 | Офлайн-режим | Room-кэш обеспечивает работу без сети, что критично при мобильном использовании |

---

## Слабые стороны (W) — внутренние недостатки

| # | Фактор | Обоснование |
|---|--------|-------------|
| W1 | Ручной ввод данных | Отсутствие официального API LDOE вынуждает наполнять базу вручную |
| W2 | Зависимость от обновлений игры | При каждом патче LDOE часть данных может устаревать без предупреждения |
| W3 | Один разработчик | Ограниченная производительность, нет ревью кода и разделения ответственности |
| W4 | Нет монетизационной модели | Сложно обосновать долгосрочную поддержку без источника дохода |

---

## Возможности (O) — внешние положительные факторы

| # | Фактор | Обоснование |
|---|--------|-------------|
| O1 | Публикация в Google Play / RuStore | Доступ к широкой аудитории игроков LDOE без дополнительных затрат |
| O2 | Расширение функционала | Калькулятор крафта, карты локаций, гайды, интеграция с календарём |
| O3 | Активное CIS-сообщество LDOE | Большая русскоязычная аудитория, потенциально заинтересованная в приложении |
| O4 | Краудсорсинг контента | Вовлечение сообщества в наполнение данных через механизм пользовательских предложений |

---

## Угрозы (T) — внешние риски

| # | Фактор | Обоснование |
|---|--------|-------------|
| T1 | Давление правообладателя (Кефир) | Возможны претензии по использованию торговой марки и игровых ассетов |
| T2 | Несоответствие требованиям платформ | Google Play / RuStore могут отклонить приложение при нарушении политик |
| T3 | Снижение популярности игры | LDOE может потерять аудиторию — целевой рынок сократится |
| T4 | Появление конкурентов | Другой разработчик может создать аналог, имея больше ресурсов |

---

## Стратегические выводы

| Стратегия | Комбинация | Действие |
|-----------|-----------|---------|
| **SO: Быстрый выход на рынок** | S1 + O1 | Использовать отсутствие конкурентов → приоритизировать публикацию MVP |
| **ST: Правовая защита** | S2 + T1 | Опираться на знание игры → использовать только fan-made данные, избегать оффициальных ассетов |
| **WO: Краудсорсинг** | W1 + O4 | Компенсировать ручной ввод за счёт вовлечения сообщества в наполнение базы |
| **WT: Модульная архитектура** | W2 + T3 | Строить систему так, чтобы обновление данных при патчах занимало минимум времени |
