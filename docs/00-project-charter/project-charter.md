## 2. Бизнес-контекст

### Проблема

В мобильной игре *Last Day On Earth: Survival* значительная часть игровой информации недоступна внутри игры — её можно узнать только методом проб и ошибок. Кроме того, встроенная система уведомлений слишком общая и не позволяет отслеживать конкретные внутриигровые события (время отката локаций, завершение крафта, восстановление энергии).

### Решение

**LDOE-Helper** — Android-приложение, решающее обе проблемы:

1. **Информационная база** — структурированный справочник по механикам, локациям, ресурсам и крафту
2. **Система событий** — гибкий конструктор таймеров и уведомлений для внутриигровых событий с поддержкой overlay-виджета поверх приложений

## 7. Границы проекта

### Включено (In scope)

- Android-приложение (min SDK 29, Android 10)
- REST API бэкенд
- CRUD для игрового контента (администратор)
- Создание, редактирование и удаление пользовательских событий
- Overlay-виджет поверх других приложений
- Push-уведомления (WorkManager + NotificationManager)
- JWT-аутентификация (access + refresh токены)
- Офлайн-режим с синхронизацией

### Исключено (Out of scope)

- iOS-клиент
- Автоматический парсинг данных из игры
- Встроенные покупки и монетизация
- Чат и социальные функции
- Веб-интерфейс для конечного пользователя
