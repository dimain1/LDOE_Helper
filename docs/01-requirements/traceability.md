# Таблица трассировки требований

## Описание

Таблица трассировки устанавливает соответствие между бизнес-прецедентами (BUC) из этапа инициации и системными Use Case (UC) из этапа требований. Обеспечивает полноту покрытия: каждый бизнес-прецедент должен быть реализован хотя бы одним системным UC. Используется для контроля скоупа и проверки требований.
